# Privacy locale — FantaAsta 2.0 A8.0.1

L'app funziona senza account, telemetria, pubblicità o invio automatico di dati.

Nel browser vengono conservati soltanto il Listone importato, il regolamento,
le rose, gli acquisti, i prezzi, le strategie, le sessioni di riparazione e le
impostazioni inserite dall'utente. Non vengono raccolti dati sanitari,
statistiche sportive o probabili formazioni.

La cancellazione dei dati del sito da Safari elimina i contenuti locali, salvo
i backup esportati. PIN e backup non sono cifrati: i file esportati devono
essere conservati dall'utente in un luogo controllato.

L'importatore ignora URL, immagini e testi editoriali non necessari. L'utente
deve usare file propri o ottenuti da una fonte che consente l'esportazione e
l'uso previsto.
